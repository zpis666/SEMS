# 临时手机访问

手机无需安装客户端，通过 Safari 打开 Cloudflare 临时 HTTPS 地址。先输入独立的访问用户名和口令，再使用系统账号登录。电脑必须保持开机、联网，后端及 Docker 容器必须运行。

入口由 `remote-access.mjs` 提供，只监听本机 `127.0.0.1:5180`。它提供前端 `dist` 构建产物，转发 `/api/v1/**`、`/api/health` 和 `/ws`。数据库、Redis、Swagger、源码和文档不通过此入口映射。浏览器访问 Cookie 带有 Secure、HttpOnly 和 SameSite=Strict 标记；业务接口仍由原系统 JWT 和角色权限校验。

每次启动随机生成访问口令，用户名为 `sems`。访问地址及口令仅输出到运行日志，不写入仓库。程序启动四小时后自动停止网关及隧道；再次启动会生成新地址和新口令。临时隧道用于开发演示，不保证持续可用。

## 启动

先按主 README 启动数据库、Redis 和后端，并在 `frontend` 目录执行 `npm run build`。本机已校验下载的 cloudflared 位于 `%LOCALAPPDATA%/SEMS/tools/cloudflared.exe`；不需要安装 Windows 服务。

在本目录运行 PowerShell 7：

```powershell
$env:SEMS_CLOUDFLARED = Join-Path $env:LOCALAPPDATA 'SEMS/tools/cloudflared.exe'
& 'E:/tools-env/nodejs-24.16.0/node.exe' './remote-access.mjs'
```

看到手机访问地址后，在 Safari 输入地址和随机口令。在前台终端按 Ctrl+C 可提前关闭该入口。

由 Codex 后台启动时，日志位于 `%TEMP%/sems-local-logs/remote.out.log` 和 `remote.err.log`，可直接要求 Codex 关闭远程入口。勿将地址与访问口令一起公开分享。
