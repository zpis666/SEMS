# SEMS v0.1.2 发布说明

**发布日期：** 2026-10-24
**修订人：** dsh+dp-v4.1-flash

## 版本重点

v0.1.2 是一次**纯前端视觉与文档**升级：确立「青绿循环 × 浅色运营工作台」设计方向，重构认证页、管理端导航、平台看板、站点工作台与用户端 H5 的视觉层级和响应式表现。**后端接口、袋状态机、角色权限、库存口径与数据库结构均未改动**，可直接替换前端静态产物升级，无需数据库迁移。

## 变更内容

- 设计令牌整体更新为循环青绿体系：主色 `#0F766E`、深青绿 `#115E59`，同步页面底色、文字、描边、图表色板与袋/订单状态色；卡片圆角 16px、控件 10px、标签 6px，阴影按卡片与浮层分层。
- 新增 `AppBrand` 统一品牌组件（袋形循环标识 + “让包装，循环新生”），支持 `compact` / `inverse` / `small` 变体，供认证页、管理端侧栏与 H5 头部复用。
- 认证页重构为桌面端「深青绿品牌叙事区 + 原创 SVG 循环插画 + 暖白表单」双栏布局，移动端收敛为品牌小标识加表单；新增 `AuthCycleVisual` 插画组件，`prefers-reduced-motion` 下停用路线动画。
- 管理端布局改为 248px 深青绿侧栏（1200px 以下收为 76px，768px 以下转抽屉 + 底部导航），头部增加日期、角色、实时同步状态与账号入口。
- 平台看板增加循环运营导语区与刷新工具条，KPI 卡改为带图标、辅助说明与悬停反馈的指标卡；ECharts 配色与图表容器样式随令牌更新。
- 站点工作台增加运营欢迎区与扫码回收主入口；用户端首页把在持额度改为品牌主卡，附近站点与进行中订单改为分层卡片；个人中心增加品牌身份卡与分层安全设置；H5 底部导航加入居中扫码主按钮。
- `index.html` 更新主题色、页面描述，并新增本地 `favicon.svg`；页面不再出现 favicon 404。
- 《系统设计说明书》10.5 视觉规范同步更新：设计方向、令牌表、Element Plus 变量映射、袋/订单状态色、看板与版面要点、禁止事项；新增 V1.4 修订记录。

## 兼容性说明

- 前端仅替换静态产物，API 路径、请求头、幂等与重试策略、路由分区与角色守卫均未变化。
- 登录页原有的回跳地址分区校验（跨区 `?redirect=/m/home` 改走角色首页）继续保留。
- 设计令牌变量名保持兼容，但**色值已变更**：如有外部样式引用 `--sems-*` 变量，会自动跟随新配色；若在令牌之外硬编码过旧色值，需一并替换。
- 视觉规范中允许在品牌区使用青绿渐变，基础组件仍限制三种圆角与轻量阴影，未引入消费级重阴影风格。

## 验证

前端 `npm run build` 通过（2344 个模块，约 1.0 秒），产物输出至 `frontend/dist/`；后端 `mvnw.cmd -DskipTests package` 通过，产出 `sems-backend-0.1.2.jar`。使用 Playwright 在 1440×1000 与 390×844 两种视口实机检查登录、注册、平台看板、用户首页与个人中心，页面无横向溢出；浏览器控制台只有评审环境下的接口鉴权失败与 WebSocket 未连接提示，没有前端运行时异常。`文档/系统设计说明书.md` 共 43 张表格校验通过。本次未重复执行后端单元测试与并发测试；后端代码未改动，v0.1.1 的测试结论仍然有效。
